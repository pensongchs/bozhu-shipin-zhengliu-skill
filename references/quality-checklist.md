# 交付前自检清单

逐项核对。任何一项不通过，就补做或明确标注，不要带着占位符交付。

## 数据

- [ ] 样本量符合 sample-plan 的建议，并写清 Top／中位／低流量各几条。
- [ ] 每期都有发布日期、标题、可见数据、时长；缺失写「未获取」。
- [ ] 所有数据注明抓取日期，没有把动态数据写成长期事实。
- [ ] 通过浏览器采集时已验证单条正片可播放、可被实际观察。画面与文案按作品核对，记录对应时间或来源；缺失项分别标明「未获取」。
- [ ] 报告和素材只保留目标博主的公开作品证据，未收录登录、验证页面或使用者账号资料。
- [ ] 至少 2 条低流量对照，且说明它们和 Top10 的具体差异。

## 01 视频数据

- [ ] Top10 每条都有「数据位置 + 选题判断 + 表达判断 + 不可复制」四句。
- [ ] 没有把「拍得好」当原因，没有写因果断言。
- [ ] 共性至少 4 条，每条能指回具体视频。
- [ ] 低流量对照是变量对比，不是简单罗列。
- [ ] 1.6 复刻思路写清了哪些数据反过来指导选题。

## 02 选题

- [ ] 每期明细覆盖样本里的所有期数。
- [ ] 写了母题分布、系列化方式、可套用公式。
- [ ] 标出了不可复刻的选题（热点、地域、身份、独家资源）。
- [ ] 复刻思路写清了可迁移／不迁移。
- [ ] 选题指令里有已发布清单，避免重复。

## 03 文案

- [ ] 开头 3 秒写了具体句式和第一条信息。
- [ ] 结构是 4—6 步，不是「总分总」这类空话。
- [ ] 给了句长、人称、高频句式的具体描述。
- [ ] 证据类型和强度写清，无来源数据单独标注。
- [ ] 复刻思路写清了可迁移的句式和结构。
- [ ] 文案指令的输入是选题 + 证据，输出含口播稿和备选开头。

## 04 画面

- [ ] 结论来自实际正片画面或用户提供的对应素材。缺少画面证据时写「未获取」。
- [ ] 人设、场景、机位、镜头节奏、字幕样式、声音都有具体描述。
- [ ] 标了不可复刻的画面资产。
- [ ] 复刻思路写清了可迁移的画面规则。
- [ ] 画面指令输出的是分镜表，列名固定。

## 05 总指令

- [ ] 自包含：AI 不读报告也能用。
- [ ] 风格包 7 项齐全：人设、受众、母题、选题公式、文案结构、画面规则、禁止项。
- [ ] 有【本次输入】槽位。
- [ ] 输出固定为：选题、标题、口播稿、分镜表、封面与发布建议。
- [ ] 自检 ≥8 条，且要求逐条回答。
- [ ] 风格包里没有残留【】。
