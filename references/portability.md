# 跨工具与抖音访问流程

## 抖音网页版

### 1. 打开目标并试播

- 检查当前对话是否有能点击、播放并读取画面的浏览器或电脑控制工具。Windows 可使用工具支持的 Edge、Chrome 或内置浏览器。优先使用未登录或用户已确认使用非主账号的可见浏览器，确保用户能在需要时接管。若已登录但账号用途不明，由用户确认；已登录主账号时，请用户改用可接管的独立浏览器个人资料或窗口。网页搜索、链接预览和只读页面文字可用于找链接和核对账号信息。
- 打开用户提供的抖音链接；只有账号名时，从 [抖音网页版](https://www.douyin.com/) 搜索并核对昵称、抖音号或主页信息，重名且分不清时再请用户确认。只访问目标账号的公开作品。
- 在目标主页打开一条公开视频，确认播放器能播放，进度变化时能看到正片画面。能直接播放就继续抽样；页面要求登录或登录遮罩挡住正片时，进入下一步。

### 2. 用户手动登录

- 在同一个可见浏览器打开抖音官方登录入口。工具支持「交给用户」或「接管」时，先使用该功能；否则请用户在同一浏览器手动操作，AI 暂停点击、读取和截屏。用户无法接管这个浏览器时，可改用工具支持且用户可接管的浏览器。当前环境没有这样的浏览器时，走素材包模式。
- 可直接提示用户：

  > 抖音要求登录才能看正片。为了保护日常运营的主账号，请在这个浏览器里用手机抖音 App 扫码，并确认登录的是你本人已有的非主账号。页面如有验证，请你本人在抖音页面按提示完成。登录好后请交回控制，或在对话里说「已登录」。密码、验证码和二维码都不用发到聊天里。

- 「已登录」即可继续，无需记录用户账号资料。登录、验证全程由用户操作。登录画面和凭据不得写进报告或素材包，也不读取或转移 Cookie。
- 遇到访问频繁、账号异常、明确限制访问等提示时，立即停止自动浏览并告知用户。用户可按抖音官方提示处理，确认可正常访问后，才回到同一个浏览器试播。保持单页逐条查看，避免并发开页和频繁刷新；不要换号、切环境或反复重试来继续访问。[抖音常见问题](https://www.douyin.com/help)

### 3. 恢复控制并核实视频内容

1. 回到原浏览器会话，再打开刚才那条作品。核对目标账号和作品，确认页面没有登录遮罩挡住正片，进度能前进，且能在两个不同时间点看到正片画面。记录链接、两处视频内时间和各自可见的内容，作为试播依据。缩略图、推荐卡片和静态封面只用于找作品。
2. 查看字幕，或在工具确实可以接收音频时核对原声。浏览器能播放声音不代表 AI 能听见。报告按作品标明口播来源和覆盖范围；只读到片段就只分析片段。记录画面时只描述观察到的镜头、字幕和包装；屏幕阅读或网页文字无法验证画面时，将画面标为「未获取」。
3. 试播通过后再按样本计划逐条打开。分别记录每条的页面数据、正片画面和口播证据，保留对应链接与时间点。仅第一个视频通过，不能据此推断其余样本。某条仍加载不出或确实无法访问时，保留可见数据和缺口；有合适的同档公开样本时可换作品。
4. 若环境只拿得到页面文字、播放器截不到实际画面、字幕或原声缺失，补所缺的一类素材即可。平台限制未解除时，改用用户已有的相应素材，写明限制。

## 素材包模式

根据缺口请用户提供可关联到作品的链接、数据截图、视频或开场／中段／结尾截图，以及原声、字幕文件或逐字稿。按实际取得的内容完成分析，缺失标明「未获取」。只拿到标题和主页信息时，交付可确认的账号数据和选题观察。

本地文件读写和浏览器控制分别判断。无法运行 Python 或写本地文件时，仍可输出 Markdown，由用户保存或在具备该能力的环境渲染。仅对话也可使用已完成的蒸馏指令生成新选题、口播稿和分镜建议。

## 指令卫生（保证跨模型稳定）

1. 纯 Markdown 或纯文本，不用 XML 标签、不用函数调用格式。
2. 变量统一用【】，一次只留一处空。
3. 单条指令 ≤3000 字；总指令过长时拆成「选题 → 文案 → 分镜」三次投喂。
4. 输出格式写死：固定小标题、固定表格列名。
5. 一次只给一个板块的素材，不要把 30 条视频和全部指令一次性塞进去。
6. 不写「你是顶级文案大师」这类空泛人设，写具体规则。

## 模型差异与应对

| 差异 | 表现 | 应对 |
|---|---|---|
| 中文短视频语感 | 海外模型容易写成书面语 | 在指令里给 2—3 个原博主的句式样例（意译，不抄原句） |
| 长文稳定性 | 超过 3000 字容易掉结构 | 分段投喂，每段只要求一个输出 |
| 表格稳定性 | 列数多时错位 | 明确列名和列数，要求先输出表头 |
| 自检执行 | 容易跳过 | 把自检项编号，要求逐条回答「是／否」 |

## 回测（交付前必做）

拿这个博主已经发过的一条爆款，遮住标题和数据，让 AI 按总指令重做一版，再和原片对比：

- 选题是否落在同一决策点；
- 开头是否在 3 秒内给出冲突；
- 结构是否同构；
- 分镜是否可拍。

复现不了，说明指令没写到点子上，回炉改指令，不要怪模型。
