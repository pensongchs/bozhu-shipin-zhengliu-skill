# 视频内容蒸馏判断框架

## 单条视频

### 一句话核心

用“对谁 + 在什么选择中 + 给出什么判断”压缩内容。不要把标题原样抄成结论。

### 开头钩子

判断钩子主要依靠哪一种力量：

- 直接后果：不做选择会损失什么。
- 选择冲突：两个都想要，但预算或条件只允许一个。
- 反常识：挑战观众已有判断。
- 身份点名：准确叫出某类人的处境。
- 未闭合疑问：先呈现异常，延迟给答案。

同时记录钩子兑现位置。只有开头刺激、正文没有兑现，不算可复用方法。

### 内容骨架

按真实顺序拆成 3—7 个节点，每个节点写清“说了什么”和“承担什么作用”。优先识别：问题、冲突、证据、反例、转折、结论、行动或评论引导。

### 证据强度

- 强：可核对数据、完整案例、清楚的现场画面或前后对比。
- 中：个人经历、多个具体例子、可理解的推理链。
- 弱：只有情绪、模糊归因、无来源数字或口号。

不要替原作者补证据。原视频没有来源时直接标注。

### 传播机制

分别判断：

- 停留：前 3—5 秒为何不划走。
- 看完：中段是否持续产生新信息或悬念。
- 评论：是否让观众暴露立场、经历或选择。
- 收藏：是否包含清单、判断标准或以后要用的信息。
- 转发：是否适合发给伴侣、父母、朋友共同讨论。

## 博主内容基因

至少从五个维度归纳：

1. 稳定受众：反复服务哪类人的哪种处境。
2. 母题：看似不同的视频背后反复讨论什么。
3. 冲突模型：钱、时间、关系、风险、身份或认知中的哪一类矛盾。
4. 判断模型：作者如何把复杂问题压成一个易传播结论。
5. 表达机制：开头、结构、证据、语气、画面和互动如何配合。

每项结论附 2—3 个视频证据。样本不足时标记“初步观察”，不要假装稳定。

## 跨博主比较

优先比较“需求与机制”，不要只比较表面话术：

- 共同服务的真实需求。
- 相同冲突的不同切入角度。
- 各自最有辨识度的证据方式。
- 已被多人验证但仍有原创空间的选题。
- 已经过度同质化、不值得继续跟进的表达。

## 事实纪律

- 链接、发布时间、可见数据和抓取日期写入索引。
- 引用只保留判断所需的短句，优先使用意译和时间点。
- 页面未显示或无法听清的内容写“未获取”，不要猜。
- 将“内容表现好”与“内容质量高”分开；缺少播放、完播或互动数据时，不判断爆款原因已经得到验证。
