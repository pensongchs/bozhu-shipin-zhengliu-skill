# 蒸馏判断框架

## 一、数据与归因

### 能拿到什么

页面可见值：点赞、评论、收藏、转发、时长、发布时间。粉丝数、作品数、获赞数只在主页看到。完播率、2 秒跳出、粉丝画像、涨粉来源通常拿不到。

所以只能做**可见数据层面的归因**：这十条的共同变量是什么，和低流量样本差在哪。

### Top10 四句法

每条必须写满四句，缺一句就是没分析：

1. **数据位置**：第几名、是中位数的几倍、收藏／评论是否异常。
2. **选题判断**：命中了什么需求，处在决策链的哪一步，冲突有多尖锐。
3. **表达判断**：开头给的是后果还是背景，结构是清单还是叙事，证据强度。
4. **不可复制**：热点、地域、身份、独家资源、平台当时的分发红利。

### 找共性，不找最高分

- 同一选题、不同讲法：比较表达差异。
- 同一讲法、不同选题：比较需求差异。
- 同一时期、不同表现：排除平台波动。
- 至少 2 条低流量对照，否则就是幸存者偏差。

### 不能写的

- 「因为标题写得好所以爆了」——没有对照，不成立。
- 「这条内容质量最高」——表现和质量是两件事。
- 把一次热点当稳定方法。

## 二、选题

### 单期

记：核心问题、冲突类型（钱／时间／关系／风险／身份／认知）、目标人群、决策阶段、数据。

### 账号级

- **母题分布**：看似不同的选题在反复回答哪几个问题。
- **冲突模型**：作者最常用哪一种矛盾，怎么把它压成一句判断。
- **系列化**：同一母题被拆成几期，是否有连续剧结构。
- **选题公式**：能用一句话概括的生成规则，例如「具体损失 + 一个明确决策 + 数字工具 + 分人群答案」。

好公式能直接生出新选题；坏公式只是复述旧标题。

## 三、文案

### 开头 3 秒

记录：第一句是什么、有没有自我介绍、用的是后果／反常识／身份点名／未闭合疑问中的哪一种、几秒内给出结论。

### 结构

拆成 4—6 个节点，每个节点写作用：给结论、否定旧标准、给逻辑、列清单、分人群、收尾。不要写「总分总」。

### 句式

句长、人称、高频句式、口头禅、情绪强度。至少摘 2—3 个意译句式做样例，不抄原句。

### 证据

金额、年限、条款、现场画面、个人经历、评论共识。标强度：强／中／弱。无来源的数字单独列出来，复刻时要求补来源。

### 结尾

一句可执行判断，还是一个开放问题？评论引导是具体问题还是「你怎么看」？

## 四、画面

检查正片的开场、中段和结尾。用实际播放画面或用户提供的对应截图，记录作品链接和能确认的视频内时间。

- **人设与信任来源**：靠职业身份、亲身经历、数据，还是情绪共鸣。
- **场景**：室内口播、实地探盘、屏幕录制、图文动画。
- **机位与景别**：固定中景、手持、特写切换频率。
- **镜头节奏**：平均几秒一个视觉变化。
- **字幕**：字体、颜色、位置、关键词强调方式。
- **包装**：常驻元素、进度条、编号卡片、贴纸。
- **声音**：BGM、音效、停顿、语速。
- **封面**：人脸／大字／对比图，和标题的分工。

缺少正片画面证据时，画面蒸馏标注「未获取」。

## 五、常见失败模式

1. **模板空转**：建了报告，核心还是「待蒸馏」。
2. **标题当结论**：把标题换个说法当一句话核心。
3. **只写观后感**：「逻辑清晰、节奏紧凑」，没有可执行规则。
4. **幸存者偏差**：只看 Top10，没有对照。
5. **因果断言**：把同时出现当成原因。
6. **替原作者补证据**：原片说「很多人」，报告写「大量案例显示」。
7. **指令不可执行**：总指令只有「模仿某某风格」，没有具体步骤和验收。

## 六、指令写法

一条合格的复刻指令包含六段：

1. **角色与边界**：你是谁，只服务谁。
2. **风格包**：人设、受众、母题、结构、句式、证据、禁止项。
3. **输入槽**：本次主题、城市、预算、人群、时长。
4. **步骤**：3—5 步，每步一个动作。
5. **输出格式**：固定小标题、固定表格列。
6. **自检**：逐条回答是／否，不通过回到对应步骤。

判断标准：把指令单独发给一个没看过报告的模型，它能不能产出结构一致的结果。能，才算蒸馏成功。
